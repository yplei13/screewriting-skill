# 07 靶心人公式（许荣哲《故事课》实战公式）

> 来源：许荣哲《故事课》套装 2 册（说故事的人最有影响力 / 好故事可以收服人心）。
> 定位：麦基讲「为什么」，许荣哲讲「怎么套公式」——这是最快的实战骨架工具，尤其适合短视频、演讲、营销、自我介绍等非长片场景。

## 核心主张：故事 vs 道理

> 纸板写「我是盲人，请帮帮我」= **道理**；
> 改成「这真是美好的一天，而我却看不见」= **故事**。

故事不是编造的消遣情节，而是「制造把人带入其中的情境，让他们跟着你一起呼吸、心跳」。故事是人类最古老的影响力工具。

## 靶心人公式：七个问题的故事公式

**1.目标 → 2.阻碍 → 3.努力 → 4.结果 → 5.意外 → 6.转弯 → 7.结局**

「靶心」就是目标：一个人只要有了目标，接下来做什么自然一清二楚。可套用在万事万物——小说、编剧、营销、品牌、自我介绍。

### 完整示范案例：褚时健与褚橙

| 步骤 | 褚时健的人生 |
|---|---|
| 1.目标 | 农村小孩，想成就一番事业 |
| 2.阻碍 | 参战当游击队员，从战场背回哥哥尸体；军人性格直接执着，常得罪人 |
| 3.努力 | 51 岁才当上破败小卷烟厂厂长；跳过烟草公司直接向烟农买货，自铺专卖店 |
| 4.结果 | 18 年创造 991 亿税收，成「烟草大王」 |
| 5.意外 | 匿名检举信，因私吞 300 万美元被判无期徒刑，时年 70 余岁 |
| 6.转弯 | 保外就医，75 岁承包 2400 亩荒山种橙子 |
| 7.结局 | 「橙子大王」，褚橙年营收数千万，成「翻身」的精神象征 |

**关键洞察**：
- 「意外之后就是转弯。**转弯的地方最好看**——那是电影的最后十五分钟，连续剧的最后一集。观众最想看的就是转弯。」
- 好故事会「自己长出脚来」传播，不用付钱（褚橙没打广告，靠故事传遍全国）。
- 同一公式可套乔布斯的一生（英雄旅程），证明公式普适。

## 一分钟/十秒钟的压缩变形

| 场景 | 工具 | 要点 |
|---|---|---|
| 一分钟 | **努力人 vs 意外人** | 两种故事原型：努力人靠「一次次努力→意外→转机」翻盘（爱迪生 1600 次试错）；意外人靠「意外→歪打正着」（伟哥：心血管药副作用变功能）。垂直思考 vs 水平思考 |
| 十秒钟 | **现实扭曲力场** | 说服人的故事：聚焦一个「意外感」瞬间（乔布斯式现实扭曲力场） |
| 自我介绍 | **姓名联想法** | 十秒/一分钟/三分钟三档：把名字变成画面与故事，让人过耳不忘 |

## 36 种剧情模式（情节数据库）

源自乔治·波尔蒂归纳，「三分钟说 5040 个故事」乃至「十八万个故事」的排列组合底层：

1. 哀求请托 2. 援救 3. 复仇 4. 亲族间的报复 5. 逃亡者的追捕 6. 灾祸 7. 不幸的遭遇 8. 反抗（革命）9. 壮举（征服）10. 拐劫 11. 谜的解释 12. 获取 13. 骨肉仇恨 14. 骨肉竞争 15. 奸情杀害 16. 疯狂 17. 因轻忽而招致损害 18. 不知而犯的恋爱罪恶 19. 无意中伤害自己所爱 20. 为了主义而牺牲自己 21. 为了所爱（骨肉）而牺牲自己 22. 为爱情牺牲一切 23. 有原因地牺牲所爱之人 24. 两种不均等的势力斗争 25. 通奸（外遇/偷情）26. 恋爱的罪恶 27. 发现所爱之人有不名誉的事 28. 恋爱发生阻碍 29. 爱上自己的仇敌 30. 野心 31. 人与神的斗争 32. 错误的忌妒 33. 错误的判断 34. 悔恨 35. 亲族的重逢 36. 失去所爱之人

**用法**：靶心人公式是「骨架」，36 种剧情是「血肉库」。定好七步结构后，从 36 种中选 1-2 种作主剧情（如《海的女儿》= 模式 22 为爱牺牲 ×《天龙八部》重组出新故事）。

## 相似物转场（故事强力胶）

场景与场景之间，用「相似物」缝合，实现丝滑跳跃：
- 经典案例：《2001 太空漫游》猿人抛起的骨头 → 画面匹配 → 太空中旋转的飞船（百万年时间跳跃）；《现代启示录》水牛与杀戮的叠化。
- 应用：从「悬疑」的地方说起、从「结局」的地方说起——倒叙与非线性叙事的缝合技巧。
- 乔布斯的人生转场：用相似物把人生段落串成传奇。

## 故事营销与逆转胜（第二册精华）

- **100% 有效的故事营销**：把自己美化成天才（苹果「不同凡想」）、把对手抹黑成笨蛋（苹果 Get a Mac vs PC）。
- **广告故事套路**：信用卡两种套路（万事达「无价」/维萨）、汽车三种切入角度（奔驰/宝马/丰田）。
- **心理营销四工具**：反差（好坏警察、三次阶梯式反差）、封闭式提问（把答案藏进问题里）、亲身经历（学习金字塔——演出来永远比说出来有效）、微电影（自主传播的病毒）。
- **逆转胜话术**：丘吉尔/威尔逊「闹场反击」、比尔·盖茨「抄袭反驳」、自嘲式认罪。

## 与主线流程的衔接（阶段 3 结构可用）

- **短视频（≤60 秒）**：直接用靶心人七步替代节拍表——目标/阻碍（钩子）→ 努力/结果（推进）→ 意外/转弯（反转）→ 结局（回味）。
- **长片**：用靶心人七步快速验骨架，再用斯奈德 15 节拍细化落点；「转弯」对应「一无所有→第三幕衔接点」区间。
- **36 种剧情模式**在阶段 2（选题）可用作「主剧情」选型数据库。

## 引导提问模板（可并入阶段 3 使用）

1. 用靶心人七步过一遍你的故事：目标是什么？谁/什么阻碍？
2. 意外发生在哪？转弯（最想看的部分）够不够狠？
3. 你的主剧情是 36 种中的哪一种？能否混搭第二种制造新意？
4. 短视频的话：十秒钩子（目标+阻碍）和最后五秒回味（结局）分别是什么？

产出：七步故事骨架 + 主剧情模式 + （短视频）钩子/反转/回味三件套。
