# 05 系统化（22 步全流程）

「系统化」是把前四层（立意、选题、结构、人物）串成一条**从创意到成品的完整流水线**，核心工具是特鲁比的完整结构步骤，叠加一份全局自检清单。

## 一、特鲁比《故事写作大师班》：完整 22 步结构

特鲁比把「七大关键步骤」展开为一条可逐格填写的完整序列（前 7 步即七大关键步骤，其后为深化与收束）：

1. **自我揭示、需求与欲望**：先想结局主角认清什么，反推开端
2. **幽灵与世界**：主角的「心魔/阴影」+ 故事世界设定
3. **弱点与需求**（W）
4. **激励事件**：打破日常、启动故事的事件
5. **欲望**（目标）
6. **盟友**
7. **对手与谜题**：对手 + 需要揭开的谜
8. **假盟友对手**：暗藏的真正威胁
9. **第一次揭示与决策**：改变欲望与动机
10. **计划**
11. **对手的计划与主要反击**
12. **驱动力**：主角被逼到只能前进
13. **盟友的攻击**：盟友的误解/冲突
14. **表面失败**：主角看似输了
15. **第二次揭示与决策**：执念驱动，欲望与动机再变
16. **对观众的揭示**：观众比主角先知道真相（戏剧反讽）
17. **第三次揭示与决策**：主角逼近真相
18. **门口、致命危机与执念**：决战前的最后考验
19. **对决**（Battle）
20. **真实自我的揭露**（Self-Revelation）
21. **道德抉择**：主角在「真理」与「旧我」之间做最终选择
22. **新的平衡点**：转变后的新秩序

**与节拍表的区别**：斯奈德/埃德森是「观众视角」的外部节拍，特鲁比是「人物转变视角」的内部步骤。二者可互相校验：外部节拍落在哪一步的内部转变上。

## 二、全流程整合自检清单（阶段 5 使用）

用以下清单把前四层串起来，逐项打钩，发现矛盾就回改：

- [ ] 立意：前提句是否贯穿全片？结局是否「证明」了它？
- [ ] 选题：类型是否清晰？是否满足该类型的核心期待？
- [ ] 结构：三幕/节拍是否完整？情节点、中点、一无所有、高潮是否都在位？
- [ ] 人物：主角弱点（W）→ 欲望 → 转变（C）是否闭环？对手是否够强？
- [ ] 逻辑：每个「揭示/转折」是否有前文伏笔？激励事件是否真的逼出欲望？
- [ ] 主题：道德论点是否通过结构（而非说教）传达？
- [ ] 张力：对抗是否贯穿每一页/每一场？赌注是否持续升级？

## 三、特鲁比「道德论点」方法（主题落地）

主题不是口号，而是「主角通过行动证明的价值观之争」：
1. 从设计原则中提炼**主题要旨**
2. 把主题拆成**正反双方的对立**（主角立场 vs 对手立场）
3. 通过**结构**（谁赢、怎么赢）而非台词说教来传达
4. 结局让主角的**道德抉择**为论点定性

## 引导提问模板（阶段 5 使用）

1. 逐格过 22 步，标注每一步的「场景/事件」落在哪里
2. 检查「三次揭示」是否层层递进，每次是否改变主角的欲望或动机
3. 道德论点：主角和对手各自代表什么价值观？谁在结局胜出，为什么？
4. 有没有「假盟友对手」？没有的话，是否需要一个隐藏威胁增强张力？

产出：完整分幕分场大纲（幕 → 场 → 每场动作、冲突、揭示）。
