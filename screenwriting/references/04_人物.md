# 04 人物（三维塑造 / 原型 / 角色网络）

人物是「立意得以被证明」的载体。三部书分别给「立体度」「原型分工」「关系网络」三个维度。

## 一、埃格里《编剧的艺术》：三维人物 + 编排 + 对立统一

### 三维人物（Physiology / Sociology / Psychology）
每个活人都由三个维度构成，缺一则人物扁平：
1. **生理维度**：体形、外貌、健康、残疾……（决定他看世界的方式）
2. **社会维度**：出身、阶级、家庭、职业、教育……
3. **心理维度**：性格、欲望、恐惧、价值观……

> 例：书中「年轻女子谋杀母亲」的案例——剧作家从生理、社会、心理三层揭示越多，戏越精彩。一个驼背的人与体形完美的人看到的世界截然不同。

### 人物编排（Orchestration）
好戏是「一组彼此对立又互补的人物」，而非一个主角单打独斗。编排要确保：
- 每两个人物之间都有清晰的**对立或互补关系**
- 人物各占一个「立场」，形成张力网

### 对立统一（Unity of Opposites）
最强的戏剧动力来自「一个人物身上不可调和的矛盾」——他既是 A 又是反 A。冲突不是外加的，而是从人物内在矛盾中自然生长出来的。

### 冲突的类型（原书划分）
- **静止型冲突**：无法升级的僵持
- **跳跃型冲突**：突然爆发的跳跃
- **升级型冲突**：步步推高的对抗（最有戏剧性）
- **冲突的预示**：提前埋下冲突的种子

## 二、沃格勒《作家之旅》：人物原型（Archetypes）

原型不是「刻板角色」，而是「故事功能」。一个角色可兼任多个原型功能：

| 原型 | 功能 |
|---|---|
| 英雄（Hero） | 观众代入的载体，承受考验、完成成长 |
| 导师（Mentor） | 给予知识、礼物、指引，常会退场 |
| 信使（Herald） | 带来改变的信号，发出冒险召唤 |
| 阴影（Shadow） | 代表英雄的对立面与恐惧 |
| 变形者（Shapeshifter） | 真假难辨，制造悬念 |
| 边界守卫（Threshold Guardian） | 挡在门口的考验者 |
| 伙伴（Ally） | 陪伴、辅助、衬托英雄 |
| 恶作剧者（Trickster） | 制造笑料与真相 |

**用法**：先定英雄「必须学会什么」（对应 12 阶段），再分配每个原型由谁、以什么形式承担。

## 三、特鲁比《故事写作大师班》：角色网络（Character Web）

特鲁比认为，单一人设不够，关键是「主角的每一个对手/盟友都对应主角的一个弱点/需求」。

- **角色网络**：每个重要角色都应「反照」主角的某一方面——对手是主角最怕成为的人，盟友是主角需要学习的人。
- **主角塑造四步**：
  1. 定主角的**弱点与需求**（W）
  2. 定**欲望**（他要什么）
  3. 定**对手**（谁与他争夺同一目标，且价值观针锋相对）
  4. 定**转变**（C，他最后变成谁）
- **假盟友对手（Fake-Ally Opponent）**：表面站在主角一边、实则是最大威胁的人，是强故事的高级配置。

## 人物塑造清单（阶段 4 输出）

1. 主角：三维（生理/社会/心理）+ 弱点 + 需求 + 欲望 + 转变（弧光）
2. 对手：目标冲突 + 价值观对立 + 强于主角（或势均力敌）
3. 盟友/导师/配角：各自承担的原型功能 + 与主角弱点的对应关系
4. 人物关系网：每两人之间的对立/互补关系

## 引导提问模板（阶段 4 使用）

1. 主角的三维：长什么样？什么出身？性格与最大的弱点？
2. 他最需要但一直逃避的「需求」是什么？（不是欲望，是内在成长）
3. 谁是他的对手？为什么「非他不可」地挡在主角面前？
4. 谁是他的盟友/导师？他们各自教主角什么？
5. 主角结尾变成了谁？（转变 C）

产出：人物表 + 人物弧光 + 角色关系网。
