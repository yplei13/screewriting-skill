# 06 落地层（对白 + 剧本格式 + 实操规则）

落地层解决「怎么真正写出来」：对白怎么写才有张力，剧本用什么格式，以及几条实战铁律。

## 一、麦基《对白》：对白的三个功能 + 六种冲突模型

### 对白的三个功能
每一句对白都应至少承担以下一项（最好多项）：
1. **解说（Exposition）**：传递必要信息，但要「化于行动中」，避免生硬交代
2. **角色塑造（Characterization）**：让观众从说话方式认出这个人
3. **行动（Action）**：台词即动作——每句话都是角色在「做」一件事（攻击/试探/讨好/隐瞒……）

**核心原则**：对白不是「说话」，是「言语行动」。角色说台词是为了改变对方、达成目的，而非解释剧情。

**对照：麦基《对白》原书的三个功能**（同一底层的另一种切分，与上面三功能并存参照）：
1. **吸引人**：勾起观众好奇——角色表面（面具）之下到底是谁？
2. **说服人**：让观众「暂时搁置怀疑」，相信虚构角色为真
3. **个性化**：每个角色的说话方式独一无二，一开口就认得出是谁

> 记法：菲尔德版回答「台词做什么」（信息/人物/动作），麦基版回答「台词为谁生效」（勾住观众/赢得信任/区隔角色）。写台词时用菲尔德版定动作，改台词时用麦基版验效果。

### 六种冲突模型（对白设计的张力来源）
| 模型 | 含义 | 代表案例 |
|---|---|---|
| 均衡冲突 | 势均力敌的正面交锋 | 《黑道家族》 |
| 喜剧冲突 | 用幽默包裹冲突 | 《欢乐一家亲》 |
| 不对称冲突 | 力量不对等的对抗 | 《日光下的葡萄干》 |
| 非直接冲突 | 表面回避、暗地交锋（潜台词） | 《了不起的盖茨比》 |
| 自反性冲突 | 角色与自我的内心交战 | 《埃尔泽小姐》《纯真博物馆》 |
| 微限冲突 | 克制、极简、留白的冲突 | 《迷失东京》 |

### 对白四类瑕疵（写完后自查）
- **可信性瑕疵**：不像这个人会说的话
- **语言瑕疵**：语言不精炼、不口语、翻译腔
- **内容瑕疵**：信息堆砌、为交代而交代
- **设计瑕疵**：违背角色/场景的冲突设计

### 角色专属对白
每个角色应有「只有他会这么说话」的独特语感。参考案例：莎士比亚《裘力斯·凯撒》、埃尔莫·伦纳德《战略高手》、《我为喜剧狂》《杯酒人生》。

## 二、悉德·菲尔德：剧本格式

标准剧本格式（便于阅读与估算时长）：
- 场景标题（Slug Line）：`内/外景 — 地点 — 日/夜`
- 动作描述（Action）：现在时、可视化的动作，不写心理独白
- 角色名居中，对白居中缩进
- 一页 ≈ 一分钟银幕时间
- 对白必须「演得出来」：把潜台词写进动作与停顿，而非括号注解

## 三、斯奈德《救猫咪》：实战铁律

1. **救猫咪时刻**：主角开场必有一个让观众共情的小动作
2. **「坏」到「有趣」**：反派/主角可以坏，但必须有趣、有魅力
3. **每一场都要有「冲突+改变」**：没有冲突的场景删掉
4. **用一句话检验**：每场戏都要能回答「谁想要什么？被什么挡住？」

## 落地写作顺序（阶段 6 使用）

1. 先写**分场大纲**（每场一句话：谁 + 想要什么 + 遇到什么障碍）
2. 再写**每场的动作描述**（可视化，推进剧情）
3. 最后填**对白**：先想「这句台词是在做什么行动」，再想措辞
4. 写完全文，用「四类瑕疵」+「三个功能」逐句自查

## 引导提问模板（阶段 6 使用）

1. 关键场次里，每句台词在「做」什么？（攻击/试探/隐瞒/请求……）
2. 主角和对手的对白属于哪种冲突模型？是否单调？
3. 有没有「为交代而交代」的解说句？能否藏进冲突里？
4. 需要我直接写出成稿，还是先出分场大纲+关键对白示范？

产出：完整剧本成稿（标准格式），或分场大纲 + 关键对白示范（按用户选择）。
