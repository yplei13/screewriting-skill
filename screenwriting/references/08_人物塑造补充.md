# 08 人物塑造补充（麦基《人物》）

> 来源：罗伯特·麦基《人物：文本、舞台、银幕角色与卡司设计的艺术》（虚构艺术三部曲收官之作，2022）。
> 定位：与 04_人物.md（埃格里三维/沃格勒原型/特鲁比角色网络）互补——麦基这一册讲「人物的本体论」：人物不是人，是人性的比喻；以及从主人公向外辐射的「卡司设计」。

## 核心命题：人物不是人

> 「人物不是人。人物之不是人，恰如《米罗的维纳斯》之不是女人。人物是一件艺术品——是对人性的一个深情的、有意味的、值得纪念的比喻。」

- 真人的生活是混沌的；人物被作者赋予了清晰的目的与弧光，比真人更纯粹、更聚焦。
- 写人物不是复制真人，而是**提炼人性本质**。人性并无趋势（四万年前窑洞壁上刻手印的人与今天发自拍的人并无二致），所以人物创作不追潮流，只追人性。

## 方法论总纲：矛盾之眼

麦基用「对照与悖论」组织整个人物体系，写作时要有一只「矛盾之眼」，在每对两极之间的光谱上找人物：

- 人物 vs 人
- 机构 vs 个人
- 特性 vs 真相
- 外在生活 vs 内在生活
- 角色（面具）vs 人物（真相）

## 两条人物灵感路径（Part 2 核心）

### 由表及里（第四章）
从外在特征切入：外貌、职业、身份、习惯、口音 → 逐步逼近内在。
适合：从观察到的真人/形象出发的作者。

### 从内到外（第五章）
从内在生活出发：欲望、创伤、价值观、恐惧 → 外化为行为与语言。
> 「将你的内在生活转化为人物的内在生活，于是人物便变成了你认识的人。」
适合：从一种情绪/人性命题出发的作者。

### 角色 vs 人物（第六章）
- **角色（Characterization）**是「表」：社会面具、职业标签、外在举止。
- **人物（Character）**是「里」：压力之下的选择揭示的真实人性。
- 观众透过表面行为（文本）窥探内心（潜文本），落差越大张力越大。

## 人物的层级进阶（第七—十三章）

| 层级 | 章节 | 要点 |
|---|---|---|
| 外在人物 | 第七章 | 可观察的行为、职业、社会功能 |
| 内在人物 | 第八章 | 未言说、无法言说的思想情感欲望（潜文本层） |
| 多维人物 | 第九章 | 表面 vs 真相、外在 vs 内在的多重矛盾叠加 |
| 复杂人物 | 第十章 | 矛盾之间相互交织、不可简单归因 |
| 完成人物 | 第十一章 | 生理/社会/心理全维度闭合（与埃格里三维暗合） |
| 象征人物 | 第十二章 | 承载主题的象征义（如《了不起的盖茨比》的绿灯） |
| 极端人物 | 第十三章 | 把某一特性推到人性极致（与立意层「前提推向极端」呼应） |

**与其他体系的衔接**：埃格里「三维人物」给骨架，麦基「多维/复杂」给深度，两者叠加使用——先用三维列出可观察项，再用矛盾之眼在每两维之间制造悖论。

## 人物宇宙与卡司设计（Part 3、4）

麦基把人物世界类比宇宙：**人物宇宙 → 银河系 → 太阳系 → 行星 → 生态 → 生命力**。

### 类型人物 / 行动人物 / 表演人物（第十四—十六章）
- 类型人物：满足类型契约的功能性人物（与 02_选题.md 的类型系统联动）。
- 行动人物：以动作推进情节的人物。
- 表演人物：读者/观众视角的「扮演」关系——观众在心里替人物完成表演。

### 卡司设计（Cast Design，第十七章）——从主人公向外辐射

| 圈层 | 角色 | 定义 |
|---|---|---|
| 核心 | 主人公 | 承载超级目标与弧光 |
| 第一圈 | **支持型角色（Supporting Role）** | 能促进场景但**不能影响事件进程** |
| 第二圈 | **服务型角色（Service Role）** | 其行动**能够影响故事事件进程** |
| 边缘 | 无名过场人物 | 世界质感的填充，卡司设计的完美收官 |

**麦基自注的关键概念**：
- **超级目标（Super-Objective）**：恢复生活平衡的需求。从激励事件开始，一直鼓舞主人公追求欲望目标（与 03/05 的「欲望」「故事脊椎」同一血统）。
- **人物弧光（Character Arc）**：人物从「表里不一」走向「表里合一」（或反方向堕落）的蜕变轨迹。

### 卡司设计检验法
1. 主人公的需求是否通过**对手**具象化？（对手 = 主人公最怕成为的人）
2. 每个支持型角色是否至少促进了一场关键场景？
3. 每个服务型角色的行动是否真的改变了事件走向？
4. 删掉任何配角，故事是否受损？不受损则该角色是「死重」，合并或删除。
5. 全卡司是否形成「彼此对立又互补」的张力网（呼应埃格里的人物编排）？

## 引导提问模板（可并入阶段 4 使用）

1. 你的人物是从「表」出发（由表及里）还是从「里」出发（从内到外）？
2. 他的「角色面具」与「人物真相」之间的落差是什么？压力下暴露什么？
3. 在哪一对矛盾上（特性 vs 真相 / 外在 vs 内在）你可以把悖论推到极致？
4. 主人公的「超级目标」用一句话说是什么？他以为恢复平衡要靠什么？
5. 卡司三圈各有哪些人？每个配角影响事件还是只促进场景？

产出：人物本体档案（面具/真相/矛盾/超级目标/弧光）+ 三圈卡司表。
