# 电影编剧 skill（Screenwriting）

## 目的

把 11 部经典编剧著作的方法论整合成一条可执行的「立意 → 选题 → 结构 → 人物 → 系统化 → 落地层」创作流水线，通过逐步提问引导用户，最终产出完整剧本（含立意句、故事梗概、人物表、节拍表、分场大纲、对白成稿）。

## 何时使用

- 用户想写电影 / 电视剧 / 网剧 / 短视频剧本或故事
- 用户提到「立意、前提、选题、类型、结构、三幕、节拍、英雄之旅、人物原型、对白、台词、分场」任一关键词
- 用户要求「写剧本」「构思故事」「搭大纲」「塑造人物」
- 用户已有成稿，要求「自查」「挑毛病」「优化剧本」「剧本诊断」→ 直接进入阶段 7

## 工作方法（核心流程）

**原则：一次只问一个阶段的问题，等用户回答后再推进，绝不一次性抛出所有问题。** 每个阶段用 AskUserQuestion 或普通提问，给出 2–4 个引导选项 + 允许用户自由填写。用户信息不足时，先按主流假设推进并明确标注，不卡住等待。

### 阶段 0：确认创作目标（先问一次）
询问：媒介（电影/电视剧/网剧/短视频）、类型偏好、时长/篇幅、用途（参赛/商业/练习）、是否已有创意或素材。
→ 记录后进入阶段 1。

### 阶段 1：立意（Premise）
引导用户确定「前提句」：一个观点 + 一个因果命题（句式「____导致____」）。
方法见 `references/01_立意.md`。产出：一句话前提（logline 雏形）。

### 阶段 2：选题 / 类型定位
帮用户锁定故事类型（10 类型之一），确定基调、受众、风格。
方法见 `references/02_选题.md`。产出：类型 + 一句话高概念。

### 阶段 3：结构
用三幕 + 节拍表搭骨架，把前提转化为 15 节拍 / 23 序列 / 12 阶段的关键节点。
方法见 `references/03_结构.md`。产出：节拍表（含情节点、中点、一无所有、高潮）。

### 阶段 4：人物
塑造主角三维 + 弱点/需求 + 对手，搭建角色网络与原型分工。
方法见 `references/04_人物.md`。产出：人物表 + 人物弧光。

### 阶段 5：系统化
用特鲁比 22 步把立意、类型、结构、人物串成完整大纲，检查逻辑闭环。
方法见 `references/05_系统化.md`。产出：完整故事大纲（分幕分场）。

### 阶段 6：落地层
写对白（三功能 + 6 冲突模型）+ 剧本格式，输出完整剧本。
方法见 `references/06_落地层.md`。产出：完整剧本（含对白成稿）。

### 阶段 7：自查优化（成稿后，可选）
剧本写完后，用《你的剧本逊毙了》100 条清单逐条自查，标记风险项并给出优化建议。**此阶段不参与创作，仅做成稿兜底排雷**。
方法见 `references/09_剧本自查清单.md`。产出：剧本自查报告（逐条核对 + 风险项 + 优化建议）。

## 最终交付物结构

完成六阶段后，输出完整剧本，包含：
1. 片名 / Logline（一句话梗概）
2. 前提句（立意）
3. 类型 + 基调
4. 人物表（主角/对手/盟友/导师/配角，含三维与弧光）
5. 节拍表（15 节拍或 23 序列）
6. 分场大纲（幕 → 场 → 每场动作与冲突）
7. 剧本成稿（标准格式，含对白）
8. （阶段 7 可选）剧本自查报告——按 `09_剧本自查清单.md` 逐条核对，标记风险项并给出优化建议
